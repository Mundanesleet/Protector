# Prospector C&D

Herramienta de prospección comercial para encontrar empresas en Bogotá y municipios cercanos (Funza, Mosquera, Chía, Cajicá, Cota, Madrid) que puedan necesitar servicios de cargue y descargue de mercancías.

> Proyecto en construcción por fases. Este README se completará en la fase final (documentación y preparación para GitHub).

## Estado actual

Fase 1-2: estructura del proyecto y configuración básica de Flask.

## Ejecución (desarrollo)

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python app.py
```
